三角形级染色探针

把 puppet 网格的**每个三角形**按所属 UV 区域染成不同颜色，用 WebGL 实际光栅化一遍。 判据：如果某块区域在贴图里有内容、在这里也能看到对应色块 → 三角形确实被光栅化了，问题在贴图采样/混合；如果那块是黑的 → 三角形没被画出来（索引、裁剪、深度或 NaN）。 模式：region 按 UV 分区上色；tri 每三角形随机色（看密度/缝隙）； tex 用真实贴图（对照）；uv 把 UV 直接输出成颜色（查 UV 是否错乱）。 右侧「区域统计」给出每个 UV 区块的三角形数与实际覆盖像素数——三角形数 >0 但像素数 =0 就是被丢弃。
